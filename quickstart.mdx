## ⚡ Basic Usage

### cURL Example

```bash
curl -X POST "https://api.ryzenths.dpdns.org/api/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ryzenth-web-compatibility",
    "messages": [
      {"role": "user", "content": "Hello, how are you?"}
    ]
  }'
```

### JavaScript Example

```javascript
const response = await fetch('https://api.ryzenths.dpdns.org/api/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    model: 'ryzenth-web-compatibility',
    messages: [
      {role: 'user', content: 'Hello, how are you?'}
    ]
  })
});

const data = await response.json();
console.log(data.choices[0].message.content);
```

### Python Example

```python
import requests

response = requests.post(
    'https://api.ryzenths.dpdns.org/api/v1/chat/completions',
    json={
        'model': 'ryzenth-web-compatibility',
        'messages': [
            {'role': 'user', 'content': 'Hello, how are you?'}
        ]
    }
)

print(response.json()['choices'][0]['message']['content'])
```
